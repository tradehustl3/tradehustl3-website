## Book cover: final wrap

- 13.57 × 9.25 in, one page, 300 ppi images. That size fits a 6 × 9 in trim with 0.125 in bleed and a spine of about 1.32 in, which matches 586 pages on white paper. Confirm against KDP's cover calculator before any reprint.
- The white box on the back cover is left blank for the barcode KDP prints.
- The front panel uses the same artwork as `public/optimized/book-cover-v2.webp`, which the website shows. Regenerate that image from this file only if the front cover changes.
